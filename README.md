# Project_for_Hackaton

Промышленный дашборд для мониторинга производства в реальном времени, построенный на архитектуре **Digital Twin**. Система агрегирует данные с производственных линий, анализирует качество, отслеживает поставки и использует **экспертную систему (Rule-Based AI)** для предсказания аварий и выдачи рекомендаций.

## 🚀 Ключевые возможности

- **📊 Мониторинг в реальном времени:** Отслеживание температуры, вибрации и загрузки оборудования.
- **⚠️ Центр инцидентов:** Автоматическая классификация проблем (Критические, Предупреждения) с цветовой индикацией.
- **🧠 AI Аналитика:** Простая экспертная система анализирует тренды и выдает прогнозы:
  - *Предсказание перегрева* оборудования.
  - *Резкий рост брака* и рекомендации по остановке линии.
  - *Прогноз необходимости ТО* на основе частоты сбоев.
- **📈 Управление планами:** Визуализация выполнения месячного плана (Onix, Cobalt, JAC J7).
- **📦 Логистика:** Мониторинг критических запасов (чипы, аккумуляторы) с автоматическими алертами.
- **🎨 Современный UI:** Адаптивный темный дизайн (Dark Mode) с поддержкой мобильных устройств.

## 🛠 Технологический стек

- **Backend:** Golang (высокая производительность, конкурентность).
- **База данных:** SQLite (легковесное хранение исторических и текущих данных).
- **Frontend:** HTML5, CSS3 (Grid/Flexbox), Chart.js (графики), FontAwesome (иконки).
- **Архитектура:** REST API + Client-Side Rendering (AJAX/Fetch).
